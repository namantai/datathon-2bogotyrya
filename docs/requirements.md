# Проверяемые требования ForteBank DATATHON 2026

Этот список составлен по корневому `AGENTS.md`. Оригинальное ТЗ «Техническое задание Datathon 26» в репозитории на этапе 01 отсутствует, поэтому внешняя сверка не выполнялась.

## Критерии оценки

| Критерий | Баллы | Проверяемый результат |
|---|---:|---|
| Обнаружение | 25 | Вердикт по всему видео с измеренными FP/FN |
| Локализация | 15 | Точный `timecode_sec` и релевантные исходные кадры |
| Классификация | 15 | Обоснованный тип каждого события |
| Нормативные правила | 15 | Реальный источник Республики Казахстан и корректная трактовка |
| Устойчивость | 10 | Работа на неизвестных видео и при другом ракурсе |
| Готовность продукта | 10 | Надёжная загрузка, статусы, понятный UI и доступный API |
| Техническое решение | 10 | Практичная переносимая архитектура и полностью локальный inference |

Сумма: 100 баллов. Скрытые тесты неизвестны, поэтому достижение 100 баллов нельзя гарантировать.

## Обязательный продуктовый сценарий

- [ ] Пользователь загружает новую запись `.mov` через Web UI.
- [ ] Во время локальной обработки отображается статус.
- [ ] Возвращается ровно один вердикт: `no_violation` или `violation`.
- [ ] При `no_violation` список `violations` пуст.
- [ ] Поддерживаются несколько недублирующихся событий в одном видео.
- [ ] Каждое событие содержит тип, числовой таймкод и осторожное описание наблюдаемых фактов.
- [x] Backend формирует для каждого тестового события 1–3 реальных JPEG-кадра из исходного MOV с фактическими PTS; релевантность кадров настоящим ML-событиям ещё не проверена.
- [ ] UI показывает проверенный нормативный источник Республики Казахстан; пункт указывается только если он подтверждён.
- [ ] Видео обрабатывается через обязательный API без ручного запуска кода.

## API и производительность

- [ ] `POST /api/v1/analyze` принимает `multipart/form-data`, поле `file`, формат `.mov` и быстро возвращает `job_id`.
- [ ] `GET /api/v1/jobs/{job_id}` возвращает `processing`, `done` или `failed`.
- [ ] Оба маршрута требуют корректный заголовок `X-API-Key`.
- [ ] Завершённый ответ соответствует [официальному контракту проекта](api-contract.md).
- [ ] Полный end-to-end цикл укладывается в лимит 5 минут на целевом оборудовании с запасом.
- [ ] Параметры обучающих видео не превращаются без основания в жёсткие ограничения загрузки.

## Локальность, безопасность и данные

- [ ] AI inference выполняется локально и после предварительной загрузки весов не требует интернета.
- [ ] Видео, кадры и их чувствительные описания не передаются облачным AI/API или другим третьим сторонам.
- [ ] Тестовые видео жюри не используются для обучения, настройки или бессрочного хранения.
- [ ] Аудио не анализируется; идентификация личности и распознавание лиц запрещены.
- [ ] Секреты, видео, кадры, разметка, веса, локальные БД и чувствительные логи не попадают в Git.
- [ ] `X-API-Key` не раскрывается во Frontend, логах и сообщениях об ошибках.
- [ ] Лицензии кода и каждого checkpoint проверяются отдельно на коммерческое использование.

## Проверяемость вывода

- [ ] Результат формулируется как признак возможного нарушения, а не юридический приговор.
- [ ] Вывод опирается только на наблюдаемые визуальные факты.
- [ ] Классы вводятся после анализа наблюдаемости и правового основания, а не как выдуманный закрытый список.
- [ ] Для каждого правила хранятся `rule_id`, наблюдаемое действие, контекст, исключения, документ, URL, подтверждённый пункт, дата проверки и ограничения трактовки.
- [ ] Нарушения по бездействию анализируются на достаточном временном контексте.
- [ ] Качество и latency измеряются честно; непроверенные показатели не заявляются.
