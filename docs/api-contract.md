# Контракт API жюри

Документ фиксирует неизменяемую публичную схему из доступных требований. На этапе 01 маршруты ещё не реализованы.

## Авторизация

Оба маршрута требуют заголовок `X-API-Key`. Отсутствующий или неверный ключ должен отклоняться. Ключ нельзя раскрывать во Frontend-коде, Git, логах или текстах ошибок.

## POST `/api/v1/analyze`

- Content type: `multipart/form-data`.
- Обязательное поле: `file`.
- Входной формат: `.mov`.
- Маршрут быстро возвращает `job_id`; обработка продолжается отдельно от исходного HTTP-запроса.

## GET `/api/v1/jobs/{job_id}`

Допустимые статусы:

- `processing`;
- `done`;
- `failed`.

При статусе `done` допустимы только два значения `verdict`:

- `no_violation` — массив `violations` пуст;
- `violation` — массив содержит одно или несколько недублирующихся событий.

Третьего вердикта официальная схема не предусматривает.

## Структура события

Каждый элемент `violations` обязательно содержит:

- `type`: строка;
- `timecode_sec`: число секунд от начала видео;
- `description`: наблюдаемые факты и осторожное объяснение;
- `evidence_frames`: от 1 до 3 кадров.

Каждый элемент `evidence_frames` содержит:

- `timestamp_sec`: число секунд от начала видео;
- `image_base64`: байты JPEG, закодированные в base64.

Кадры должны быть реальными исходными кадрами соответствующего видео и совпадать с указанными временными метками.

## Пример завершённого ответа

```json
{
  "job_id": "example-job-id",
  "status": "done",
  "verdict": "violation",
  "violations": [
    {
      "type": "Проверенный тип возможного нарушения",
      "timecode_sec": 44.2,
      "description": "Наблюдаемое действие, требующее проверки по связанному правилу",
      "evidence_frames": [
        {
          "timestamp_sec": 44.2,
          "image_base64": "BASE64_JPEG_BYTES"
        }
      ]
    }
  ]
}
```

Пример служит будущему контрактному тестированию и не является результатом реального анализа.

## Нормативная связь в UI

UI обязан показывать нормативный источник, но предоставленный JSON-пример жюри не содержит отдельного поля для него. Связь должна храниться во внутреннем результате сервиса и предоставляться UI безопасным согласованным способом, не меняющим официальные пути, поля, типы и enum без отдельного согласования.

## Временное ограничение

Весь end-to-end цикл — очередь, декодирование, inference и доступность ответа — должен завершаться менее чем за 5 минут на целевом оборудовании с практическим запасом.
